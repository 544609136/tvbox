## 点播源分两类

| 类别 | 数量 | 说明 |
|---|---|---|
| **真直链** | **147** | 播放地址是 m3u8/mp4，**不需要解析器**，桌面端也能播。按吞吐降序排。 |
| **需解析器** | 15 | 地址指向爱奇艺/芒果等网页播放页，靠 `parses` 解析。手机/电视端可用，**桌面端会挂**，已单独分组。 |

> 吞吐最高的真直链：爱奇艺资源 1955KB/s、暴风影视 596KB/s、dd资源 291KB/s、极速 257KB/s。
>
> **本轮修正的一个测速假象**：旧方法只判断「能不能拉到字节」，把爱奇艺网页 HTML 当分片算，
> 测出假的 646KB/s。现在必须先确认「拉到的是 m3u8 索引或 ftyp」，再算吞吐 ——
> 这类源的真实身份是「需解析器」，不是直链。

## 关于成人标记

站点名称带 `**` 前缀（同时带 `adultFlag: true` 字段）的是**成人疑似源**。
它们**全部保留、没有被删除**（合并仓里 34 条），标记只是提示，请自行判断取舍。
标记基于名称特征匹配，**存在误伤可能**（实测同一 host 的两条源会被一标一不标，
详见 `cur/成人源清单.md`），不要把标记当结论。

## 关于「需补类」

少数 type3 站的 `csp_XXX` 类不在 `spider_special.jar` 里（32 个类）。
这些站**仍然保留**在合并仓中，分组标为「特殊功能·需补类」，不会因为缺类被删。

## TVBox 用法

设置 → 配置地址 → 填上面那个 `multi_cn.json` 地址，或扫码导入。

## 已知限制

- 站点可用性随上游采集接口变化，配置是某次实测的快照，不保证长期有效。
- 顶层 spider 是图床直链（约 0.9MB），**不能走 jsDelivr**（>20MB 会 403），请用 raw 或 gh-proxy。
- 直播源实测下行有限（部分源 300–500KB/s），卡顿多为源带宽上限，非配置问题。
